# NAS
Что такое NAS

NAS или же Network Attached Storage - это сетевое хранилише данных, представляющее собой компактный компьютер с жесткими дисками подключенный к локальной сети или интернету. Оно обеспечивает централизованный, круглосуточный доступ к файлам, резервное копирование и создание личного "*облака*" для дома или офиса.

Конкретно сейчас рассмотрим samba на дистрибутиве Ubuntu Linux, ПО которое будет использоваться Samba. Это универсальное свободное программное обеспечение, которое позволяет компьютерам на базе Linux/Unix полноценно взаимодействовать с системами Windows в одной локальной сети.

Основные сегменты ИТ где используется Samba:

 + Общий доступ к файлам: позволяет открывать папки на Linux сервере так, будто это сетевые диски Windows
 + Общие принтеры: делает принтеры, подключенные к Linux, доступными для пользователей Windows
 + Контроллер домена: начиная с версии 4, Samba может выступать в роли аналога Active Directory (AD) для управления учетными записями и правами доступа.

 Samba использует сетевой протокол SMB (Server Message Block), который является родным для операционных систем Microsoft. Благодаря этому Windows-клиенты видят Linux-машину в "Сетевом окружении" без установки дополнительного ПО.

Переходим к файлу конфигурации *smb.conf*, это основной конфигурационный файл сервера samba, который определяет правила доступа к файлам и принтерам в сети. Он имеет структуру, схожую с Windows INI-файлами, и состоит из разделов (секций), параметров и коментариев

Секции это заголовки заключенные в квадратные скобки *[]*. Каждая из секций описывает либо глобальные настройки сервера, либо отдельный сетевой ресурс (шару).

Основные секции:

 + *[global]* - содержит настройки, влияющие на работу всего сервера (название рабочей группы, тип безопасности, логирование)
 + *[homes]* - специальная секция для автоматического создания персональных домашних директорий пользователей
 + *[имя_ресурса]* - пользовательские секции (например public или share), описывающие конкретные общие папки
 + *[printers]* - настройка для общего доступа к принтерам

Далее параметры, записываются внутри секций в формате *имя_параметра = значение*, параметров достаточно много. Перейдем к файлу, снизу дописываем пару секций с общесетевым ресурсом и перезапускаем службу, см. рисунок ниже.

По ходу решение данной лабораторной работы могут возникнуть несколько проблем, не забудьте выдать права на общесетевые папки с помощью команды *chmod*, так же убедитесь что пользователь под которым вы пытаетесь пройти аутентификацию реально существует на сервере.

Еще пару слов про samba как решение. В профессиональных больших продакшенах и в целом в крупных IT инфраструктурах обычная реализация samba на базе стандартных ОС редко используется в качестве основного сетевого хранилища из-за ограничений в производительности, масштабируемости и надежности. Для работы с большими объемами данных и обеспечения высокой доступности данных применяются специализированные NAS/SAN-решение на базе такиех систем, например как TrueNAS (ZFS), которые предлагают продвинутые механизмы кэширования, снэпшоты файлов и промышленную отказоустойчисвость.

Такие системы, как TrueNAS Enterprise или решения от Dell EMC и Isilon, оптимизированы на уровне ядра для параллельной обработки огромных потоков данных, что критично для многопользовательского пользования. В то время как samba-шара может стать "узким местом" и привести к деградации файловой системы при высоких нагрузках.
